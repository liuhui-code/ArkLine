# Domain Docs

ArkLine uses a single-context documentation layout.

Before exploring a domain, read `CONTEXT.md` at the repository root and relevant ADRs under `docs/adr/` when those files exist. Proceed silently when they do not exist.

Use glossary terms from `CONTEXT.md` in issues, tests, hypotheses, and implementation notes. Surface conflicts with an existing ADR explicitly instead of silently overriding it.
